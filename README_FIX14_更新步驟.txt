小怪獸售票機 V7.8.3.3 FIX14 更新步驟

本次只更新 GitHub Pages 網頁。
Controller 113 不需要重新安裝。

1. 將本資料夾內全部檔案依原路徑覆蓋到目前 ticket 專案。
2. 等待 GitHub Pages 部署完成。
3. 完全關閉點餐機售票頁，再重新開啟。
4. 第一次開啟時，新 Service Worker 可能會自動重新載入一次，屬正常現象。
5. 右下角確認顯示：
   V7.8.3.3 · FIX14 STARTUP HOME + BACK GUARD

更新後測試：

A. 開機／重開售票頁
- 沒有付款進行中時，應顯示首頁。
- 不應直接停在「請選擇票種」。

B. 返回首頁
- 首頁按「開始購票」。
- 進入「請選擇票種」後按「返回」。
- 應立即回首頁。

C. 現金保護
- 開始現金付款但尚未投入任何金額，可以取消後返回。
- 若已投入任何現金，仍禁止直接返回。

D. 現金明細
- 應繼續顯示應付、已投入、尚差、票券數量、紙鈔、硬幣與投入面額。

不要清除點餐機瀏覽器資料，不要解除安裝 Controller 113。

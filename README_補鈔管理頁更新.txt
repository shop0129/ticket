小怪獸售票機 V7.8.3.3／Sprint 11K 後台補鈔與正式找零狀態更新

包含：
1. index.html
2. js/hardware/coin-manager.js
3. css/coin-manager.css

功能：
- 「開始補鈔」
- 「補鈔完成，檢查並恢復」
- 不輸入、估算或限制百元鈔張數
- XC100 缺鈔時自動停用百元找零
- 只有硬體回報 READY 才恢復百元找零
- 顯示正式自動找零中的訂單、應找、已找與尚欠金額
- 保留既有開始補幣、硬幣庫存與安全門檻

套用方式：
- 先備份目前售票網頁專案。
- 將本資料夾三個檔案依相同相對路徑合併到目前網頁專案。
- 若目前網站已有其他未合併修改，不要直接整份盲目覆蓋 index.html。
- 部署 GitHub Pages 後，重新整理點餐機售票頁。

注意：
- 這些檔案不會由 Android Controller 安裝程式自動部署。
- 補鈔流程只在按「完成」時送 XC100 唯讀 STATUS，不會出鈔。
- 正式找零由 Controller 110 控制；後台網頁無法直接送出款封包。
- 目前實機四種硬幣各 3 枚，必須先補到高於安全門檻。

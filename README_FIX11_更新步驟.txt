測試方式：

1. 任選一張票進入付款頁。
2. 選擇「現金付款」。
3. 尚未投入現金前，畫面就必須顯示：
   應付／已投入／尚差／票券數量／紙鈔數量／硬幣數量。
4. 投入現金後，金額、數量與面額明細必須立即更新。
5. 付款完成後，列印百分比應平順增加，不可再由 0% 直接跳到 94%。
6. 實體收據列印成功後才可顯示 100%。

1. 確認右下角不是 FIX10。
